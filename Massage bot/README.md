# Telegram-бот для записи на массаж

Бот для автоматизации записи клиентов на услуги массажа.

## Функционал

- Регистрация клиентов (имя, возраст)
- Выбор услуги (расслабляющий, лечебный, антицеллюлитный)
- Календарь с выбором даты и времени
- Блокировка прошедших дат и ограничение на 1 месяц
- Проверка на дубли записей
- Админ-панель для мастера:
  - Просмотр новых заявок
  - Подтверждение/отмена записей
  - Блокировка дат
  - Статистика
- История записей клиента
- Отмена записи клиентом
- Напоминания за день и за час
- Система отзывов с оценками

## Стек

- Python 3.11
- Aiogram 3
- SQLite (aiosqlite)
- python-dotenv

## Установка

1. Клонируй репозиторий:
   git clone https://github.com/твой_ник/название_репо.git

2. Установи зависимости:
   pip install -r requirements.txt

3. Создай файл .env и добавь токен:
   BOT_TOKEN=твой_токен

4. Запусти бота:
   python main.py
